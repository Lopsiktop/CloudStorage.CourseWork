# Гайд по установке облачного хранилища на локальный компьютер

1. Распаковать архив
2. Открыть проект в Visual Studio 2022
3. Зайти в appsettings.json проекта CloudStorage.WebApi и поменять "ConnectionStrings" настройку "SqlServer", указав вместо "Server=DESKTOP-C0LRN55;" - "Server={наименование вашего сервера}"
4. Запустить Sql Server Management Studio (SSMS)
5. Выполнить скрипт script6.sql в SSMS
6. Можно запускать проект

## Добавление админа

1. Зарегистрировать нового пользователя, используя работающий клиент
2. В БД поменять поле пользователя IsAdmin с 0 на 1 (средствами Sql Server Management Studio)
